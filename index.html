04

Three lines to ship it.

Every indicator inherits currentColor, so it picks up your text colour automatically.

1Install

From npm, or straight from a CDN.

npm i hmm.css

<!-- or -->
<link rel="stylesheet"
  href="https://unpkg.com/hmm.css">

2Drop in markup

Most indicators are a single class. No JS needed.

<span class="hmm-shimmer">
  Thinking
</span>

<span class="hmm-caret"></span>

3Animate text optional

Use attributes, or call the helpers directly.

import "hmm.css/auto";

import { cycle } from "hmm.css/js";
cycle(el, ["Thinking", "Searching"]);
PropertyDefaultWhat it does
--hmm-durationper indicatorLength of one cycle.
--hmm-sizeper indicatorSize of the shape indicators.
--hmm-highlightlighter textColour of the shimmer sweep.
--hmm-a … --hmm-dviolet, cyan…Palette for aura, sparkle, blob and trace.
--hmm-radius / --hmm-width12px / 1.5pxCorner radius and stroke width for .hmm-trace.
